# dsh-whale-post-cli

零依赖命令行（★**它是入口工具，不是插件** ✗）

* 提供接口：（无：它是命令行，不是插件 ✓）
* 依赖接口：`whale.bus`、`whale.roster`、`whale.types`、`whale.gate`、`whale.deliver`、`whale.verify`
  （★**自己把它们拼起来** —— 这一手在源码里叫 `wire()` ✓）
* 自测：`node selftest.mjs`（**只看退出码**：0 过／非 0 不过）

## 命令

| 命令 | 干什么 |
|---|---|
| `hello --as <谁>` | ★握手（★协议不许"像 UDP 那样"直接发 ⇒ 没握过手不许发信 ✓） |
| `send --as <谁> --to <谁\|组> --subject <题> --body <正文>` | ★发一封；★可选 `--mode online\|offline`／`--type <类型>`／`--re <父信 id>`／`--force`／`--live a,b` |
| `pump --as <谁> [--keep]` | ★收信（★**没有读者时一封都不消费** ✓） |
| `quota --as <谁> [--days N]` | ★查配额（★离线件按"条"、不计单位 ✓） |
| `verify [--enable\|--disable] [--allow a,b]` | ★**看安全校验状态／开关**（★默认禁用 ✓；禁用中会提示开启 ✓） |
| `nag` | ★**看该不该提示**（★未开启时每天至多一次，连提三天后不再提 ✓） |
| `roster`／`types`／`key` | ★看名单／看类型／看密钥指纹（★**密钥本体不打印** ✗） |
| `selftest` | ★端到端自测（★临时目录，**不碰真数据** ✓） |

## 通用参数与退出码

* ★`--root <目录>`：★信箱根（★默认 `./.whale-mail`，或环境变量 `WHALE_POST_ROOT` ✓）
* ★`--roster <名单 json>`：★名单文件 ✓
* ★`--live a,b`：★**声明"这些人此刻有活体会话"** ✓（★在线件才会真投出去 ✓）
* ★`--allow a,b`：★安全校验的白名单 ✓

| 退出码 | 意思 |
|---|---|
| `0` | ★成功 ✓ |
| `2` | ★**拒发／输入不合法** ✓（★配额／回环闸／未注册类型／未知收件人／空正文／`mode` 写错…） |
| `1` | ★没料到的错 ✓ |

★★**判据看退出码，不要看输出里的中文** ✗。

## 它守的两条线（★）

* ★★**`--body` 不许冒充参数** ✗ —— `--body --force` 会被当成"正文＝`--force` 且带 `force`" ⇒ **顺手把三道闸全绕过去** ✓；
  选项值以 `--` 开头一律当写错（退出码 2 ✓）。
* ★★**参数顺序无关** ✗ —— ★`--as`／`--to` 写在命令前后都行 ✓。
* ★**用 npm 上那一份**：`npx -y dsh-whale-post-cli@0.2.0 <命令>` ✓（★不用 clone、不用 `npm install` ✓）。
